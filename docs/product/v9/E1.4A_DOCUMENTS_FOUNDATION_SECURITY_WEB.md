# E1.4A — Documents foundation/security/web

> Macro-PR A da E1.4. **Nao aplicar migration 073 em producao sem
> `OWNER_MIGRATION_GATE_E14A`.** Sem Asaas, sem env/secrets, sem escrita de dado
> de negocio em producao.

## Escopo

- Documentos de frete continuam no bucket privado `fretes-documentos`; legado
  publico `comprovantes` segue intacto para fluxos antigos.
- Contrato v2 de upload: `document_contract_version=2`; documentos `outro`
  exigem `nome_documento` ou `descricao` no backend.
- Upload seguro para retry com `client_request_id` em documentos e evidencias ePOD.
- Auditoria minima para documento operacional: `uploaded` e `cancelled`, com
  ator, papel, timestamp, source, reason e metadata.
- Fundacao de multiplos recebedores/signatarios operacionais em
  `frete_documento_participantes`, separada de contratos SaaS.
- Web prioriza preview interno de PDF/imagem via signed URL curta; abrir fora,
  salvar e compartilhar ficam como acoes secundarias.
